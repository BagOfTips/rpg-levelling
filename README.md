# RPG Levelling

A small Obsidian plugin that adds RPG-style levelling progress to the active editor pane.

![Alt Text](https://media0.giphy.com/media/v1.Y2lkPTc5MGI3NjExbGl5emZybG83YTN0dzlwcTNubm0xM3dtMHNpb3RydmV2b3p0aDc1YiZlcD12MV9pbnRlcm5hbF9naWZfYnlfaWQmY3Q9Zw/5ZnJhpJiu1foUfBlo1/giphy.gif)

## What it does

- Awards 1 XP for each character added while editing notes.
- Shows a compact `Lv` label, progress bar, and current XP in the focused note pane.
- Levels scale forever with no maximum level.
- Each level takes more XP than the last.
- Plays a small level-up animation when a new level is reached.
- Keeps a backup copy of progress in Obsidian app storage so plugin updates can restore your level and XP.
- Lets you choose the widget corner in plugin settings. The default is bottom right.

## Commands

- `Show RPG levelling progress`
- `Reset RPG levelling progress`
